# Decision records

The big choices, one short file each: the context, the decision, what it rules out, and its status. A record is never
rewritten; a new record supersedes it ("Status: superseded by NNNN"). Format after Michael Nygard's records
(https://docs.arc42.org/tips/9-5/). Add one when Sam decides something structural or when you make a choice the next
agent must not undo by accident. Number = next free four-digit number.
