# KINOFORGE project memory (index only)

This folder is Muse Code's committed project memory. KINOFORGE keeps all of its memory in `docs/`, shared by every agent,
so this index only points there. Do not write facts here; write them where `docs/MEMORY.md` says.

- `AGENTS.md`: start here (session start, read order, rules and their gates, definition of done, map)
- `docs/STATUS.md`: where things stand now
- `docs/LOG.md`: dated history, newest first, append-only
- `docs/SOUL.md`: taste and judgement, Sam's verdicts, house styles
- `docs/MEMORY.md`: which file holds what, who writes it, when
- `docs/decisions/README.md`: decision records
- `docs/PLAYBOOKS/README.md`: one playbook per recurring job
- `docs/LESSONS.md`: studio-wide traps; `films/director/LESSONS.md`: the director's lessons
- `films/director/CRAFT.md`: the craft rules for films
- `tools/verify.sh`: every gate in one command
